# اللي عليك — بالترتيب

كل بند مكتوب فيه: وين تروح بالضبط، شو تعمل، وليش. وبآخر كل قسم مكتوب شو بعمل أنا بعده.

**قاعدة واحدة قبل كل شي: لا تكتب أي مفتاح أو توكن بالمحادثة.** كلهم بينحطوا بالسيرفر مباشرة، وسكربت التجهيز مكتوب أصلاً عشان ما يمرقوا مني. قلّي «جاهز» بس.

---

## القسم ١ — الآن، وما بيستنى شي (١٠ دقايق)

### ١.١ سجل الـ DS — الوحيد المستعجل

**المشكلة:** سجلّ `.shop` العالمي لسا فيه:

```
souq48.shop.  DS  15310 13 2 B0419A50...
```

هاد مفتاح Spaceship، بينما Cloudflare صارت هي اللي بتجاوب. يعني السجلّ الأب بيقول «هالنطاق موقّع» وما في توقيع. بعض الـ resolvers بتقبل وبعضها بتعطي **SERVFAIL** — الدومين بيختفي، مش بيبطئ.

**شو تعمل:**

1. افحص أولاً — افتح هالرابط بالمتصفح:
   `https://dns.google/resolve?name=souq48.shop&type=DS`
2. إذا الرد فيه `"Answer"` → لسا موجود.
   إذا فيه `"Status":0` بلا `Answer` → **انسحب لحاله وخلصت، تجاهل الباقي.**
3. إذا ضلّ موجود بعد ساعتين من تغيير الـ nameservers:
   راسل دعم Spaceship (زر **Support** فوق بلوحتهم) واكتب:

   > Please remove the DS record for souq48.shop. The domain now uses external
   > nameservers (Cloudflare) and the stale DS breaks DNSSEC validation.

**ليش انت مش أنا:** لوحة Spaceship بتعرض `0 records` بتبويب DNSSEC وبتعطي زر «إضافة» بس — ما في زر حذف لسجل منشور أوتوماتيكياً. لازم دعمهم.

### ١.٢ احذف سجلّي A تبع صفحة الإيقاف

Cloudflare ← `souq48.shop` ← **DNS** ← **Records**

في سجلّين `A` على الاسم `souq48.shop`:

- `54.149.79.189`
- `34.216.117.25`

**هدول مش سيرفرك.** سيرفرك `179.198.198.119`. هدول عناوين AWS تبع صفحة انتظار حطها المسجّل — يعني دومينك هلأ بيخدم صفحة حدا تاني تحت شهادتك.

اضغط **يحرر** على كل واحد ← **حذف**. الزون بيضل فاضي، وهاد صح: ما في إشي نوجّه عليه لسا.

## القسم ٢ — تجهيز Cloudflare (٢٠ دقيقة)

### ٢.١ توكن الـ DNS

Cloudflare ← أيقونة الحساب فوق يمين ← **My Profile** ← **API Tokens** ← **Create Token**
← **Create Custom Token**

| الحقل | القيمة |
|---|---|
| Token name | `souq48-caddy-dns` |
| Permissions | `Zone` · `DNS` · `Edit` |
| Zone Resources | `Include` · `Specific zone` · `souq48.shop` |

**لا شي غير هيك.** هاد التوكن بيقعد بسيرفر متصل بالإنترنت — أي صلاحية زيادة فيه هي صلاحية تنسرق مع السيرفر. وظيفته الوحيدة إنه يكتب سجل `_acme-challenge` عشان شهادة الـ wildcard تنصدر، وما في طريقة تانية تصدر شهادة لـ `*.souq48.shop`.

خزّنه بمدير كلمات المرور. **لا تكتبه هون.**

### ٢.٢ رقم الـ Zone

Cloudflare ← `souq48.shop` ← **ملخص (Overview)** ← عمود يمين ← **Zone ID**. انسخه — مش سر، بس بحتاجه بالـ `.env`.

### ٢.٣ باكتين على R2

Cloudflare ← **R2** بالقائمة اليسار ← **Create bucket** (مرتين):

| الاسم | الموقع | ليش منفصلين |
|---|---|---|
| `souq48-media` | Automatic | صور المنتجات — بتنخدم للعالم عبر CDN |
| `souq48-backups` | Automatic | نسخ قاعدة البيانات مشفّرة — **ما بينخدم لحدا** |

**ليش باكتين مش واحد:** مفاتيح الميديا بتقعد بحاويات الويب والـ worker، وهي الوحيدة المعرّضة للإنترنت. لو انسرقت، لازم ما تعطي كمان كل نسخة احتياطية تاريخية للمنصة كلها.

### ٢.٤ تلات أزواج مفاتيح R2

R2 ← **Manage R2 API Tokens** ← **Create API token** (تلات مرات):

| الاسم | الصلاحية | البكت | مين بيستعمله |
|---|---|---|---|
| `souq48-media` | Object Read & Write | `souq48-media` | حاويتا الويب والـ worker |
| `souq48-backup-write` | Object Read & Write | `souq48-backups` | حاوية النسخ الاحتياطي |
| `souq48-backup-read` | **Object Read only** | `souq48-backups` | شاشة النسخ بلوحة الأدمن |

التالت **قراءة فقط** بقصد: الشاشة اللي بتعرض النسخ بتقعد بحاوية الويب، والزوج التاني بيقدر يمسح كل نسخة تاريخية. حاوية متصلة بالإنترنت ما لازم تحمل مفتاح بيقدر يمسح.

### ٢.٥ نطاق عام للميديا

R2 ← `souq48-media` ← **Settings** ← **Custom Domains** ← **Connect Domain** ← `cdn.souq48.shop`

**وبعدها فوراً — الخطوة اللي حذّر منها `docs/DEPLOY.md`:**

ربط نطاق عام على البكت **بينشر كل مفتاح فيه**. وهاد بيشمل `tenants/{id}/_exports/...zip` — وهو **نشاط تجاري كامل بملف واحد**، على مفتاح متوقَّع بالتصميم. عشان هيك التصدير ببكت منفصل بلا وصول عام: كل شي بالبكت التاني ما بينوصله إلا برابط موقّع بينصدر لكل طلب لحاله.

**لا تربط أي نطاق عام على `souq48-backups`. أبداً.**

## القسم ٣ — قبل الإقلاع (١٥ دقيقة)

### ٣.١ مفتاح تشفير النسخ الاحتياطية

على **جهازك**، مش على السيرفر:

```
winget install FiloSottile.age
age-keygen -o souq48-backup-identity.txt
```

بيطلعلك سطرين:

- `Public key: age1...` ← **هاد بيروح للسيرفر** (`BACKUP_AGE_RECIPIENT`)
- الملف `souq48-backup-identity.txt` ← **هاد ممنوع يلمس السيرفر**

حطه بمدير كلمات المرور. **هاي مش شكليات:** حدا بياخد السيرفر بياخد قاعدة البيانات الحية — وهاد كان رح يصير على كل حال. بس بدون هالملف، ما بياخد **أربعتاشر يوم من نسخ كل تاجر مرّ على المنصة**. وبنفس الوقت: تضيّع الملف = تضيّع كل النسخ الاحتياطية. ما في نسخة تانية منه بالدنيا.

### ٣.٢ مفاتيح الإشعارات

```
npx web-push generate-vapid-keys
```

زوج مفاتيح. خزّنهم — بينحطوا بالسيرفر.

### ٣.٣ البريد

سجّل على [resend.com](https://resend.com) ← أضف `souq48.shop` ← بيعطيك سجلات SPF و DKIM و DMARC تحطها بـ Cloudflare DNS. خد الـ API key.

بلا هالخطوة رسائل «عيّن كلمة مرورك» بتوصل للسبام أو ما بتوصل — وهاي الرسالة اللي كل تاجر بيدخل فيها للمنصة أول مرة.

### ٣.٤ بريدك

قرر أي بريد بيستقبل:

- `ACME_EMAIL` — تنبيهات انتهاء الشهادات من Let's Encrypt
- `SEED_SUPER_ADMIN_EMAIL` — حساب مالك المنصة

لازم بريد بتفتحه فعلاً. الافتراضي بـ `.env.example` ممنوع يوصل للإنتاج — مكتوب بالمستودع وعلني.

## القسم ٤ — السيرفر (القرار الوحيد اللي بده تفكير)

الـ VPS الحالي مدفوع **لسنة كاملة** ($203.88 لحد 2027-08-31)، وعليه 7.4 جيجا رام و95 جيجا قرص فاضية.

واللي عليه — `itqantech.io` — طلع **موقع ستاتيك**. يعني بينخدم من Caddy تبع المنصة بكتلة `file_server` وحدة، بلا تعارض.

| | |
|---|---|
| **نفس السيرفر** | ما بتدفع إشي. بنحط `itqantech.io` جوّا Caddy تبع المنصة. خطره: كل إعادة نشر للمنصة بتلمس موقع شركتك — وبناخد snapshot قبل |
| **VPS تاني** | $13.99 أول شهر (KVM 2). فصل كامل: موقع شركتك ما بيتأثر بأي إشي بالمنصة |

**رأيي:** جرّب على الحالي. تكلفته صفر، والفصل ممكن تعمله لاحقاً بنقل حاويات — أسهل بكثير من العكس. وقبل أي إشي بناخد snapshot.

**بس القرار إلك، والشرا مصاريفك — أنا ما بضغط زر شرا.**

## بعدها أنا

قلّي «جاهز» ومعك الدومين والسيرفر، وبكمّل:

1. سجلات DNS على Cloudflare (A للجذر و wildcard، و CNAME للـ cdn)
2. تجهيز السيرفر بالسكربت الجاهز (`deploy/hostinger-post-install.sh`) — Docker، جدار ناري، swap، وتوليد الخمستاشر سر اللي بيتولّدوا ذاتياً
3. تعبئة الـ `.env` — بتلصق المفاتيح بالسيرفر مباشرة وأنا ما بشوفهم
4. `docker compose build && up` + الترحيلات + البذور
5. تشغيل البوابات على السيرفر، وإكمال إخفاقات الـ e2e الباقية
